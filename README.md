# فيها ولا فمصريها

لعبة ورق في المتصفح: مزايدة على الأكلات، جوكر كبير وصغير، باوند، وكشف.
تلعب ضد الكمبيوتر، أو تسوي طاولة ٤ أو ٦ لاعبين وتلعب مع ربعك، مع الكلام بالصوت.

## الملفات

| الملف | وش هو |
|---|---|
| `index.html` | اللعبة نفسها، وهو اللي يفتحه GitHub Pages |
| `baloot.html` | المصدر اللي نعدّل عليه (نفس اللعبة بدون إعدادات Firebase) |
| `build_site.py` | يطلّع `index.html` من `baloot.html` ويضيف إعدادات Firebase |
| `firebase-config.json` | إعدادات مشروع Firebase (مو سرية، اللي يحمي البيانات هي القواعد) |
| `firestore.rules` | قواعد الحماية في Firebase: الطاولات مفتوحة للاعبين اللي دخلوا بس |

## التحديث

بعد أي تعديل على `baloot.html`:

```
python3 build_site.py
```

وبعدها ارفع `index.html` الجديد.
